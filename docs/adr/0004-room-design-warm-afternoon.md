# ADR-0004：部屋デザインは "Warm Afternoon Room" を採用

- 状態：採択（2026-04-18）
- 文脈：companion-desktop のアバター窓背景

## 決定

- パレットは `docs/ROOM_DESIGN.md` の A-2 "Warm Afternoon Room" を採用。
  クリーム／オーカー主体 + サージュ緑のワンポイント。
- 構図は以下を守る：
  - 三層構成（foreground / midground / background）を明示。
  - 窓は画面のバック・サード（アバターと反対側）に置き、対称配置を避ける。
  - アバターのシルエット周辺に最高輝度・最大彩度を残し、背景はそれより
    20〜40% 低彩度。
  - 時間帯は「午後の斜光」に統一。暖色の指向性光源は一つだけ。
- モチーフは `docs/ROOM_DESIGN.md` §C から 5〜7 個以内で選ぶ。密度過多を
  避ける。

## 根拠

- スライス・オブ・ライフ系の背景画法とコントラスト理論に整合
  （出典：`docs/ROOM_DESIGN.md` §E）。
- VRM アバターの肌色（暖色）と競合しない低彩度クリームが土台になる。
- サージュ緑一点で目線を誘導し、ソリッドなアンカーダーク（`#6B4E3D`）で
  パステル・マッドを回避。

## 結果

- 以降の CSS 部屋編集はこの ADR とパレットに沿って行う。違う方向に振る
  場合は新しい ADR（0005 以降）を立てる。
